# D5: Shapes (Draw and Snap) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Shape tool with dropdown for direct shape drawing, enhance the Snap Shapes toggle for pen mode, add shape options (stroke/fill), add Shift key constraints, and add a unit test for shape recognition.

**Architecture:** 
- Extend the existing `shape` tool mode in InkEngine to support direct shape drawing (not just freehand recognition)
- Add a shape type selector in the ribbon (dropdown with Line, Arrow, Rectangle, Rounded Rectangle, Ellipse, Triangle, Star)
- Add a shape options popover with stroke color, stroke width, fill color, fill opacity
- Enhance the existing `shapeRecognition` toggle to work with pen mode for snapping freehand to perfect shapes
- Add Shift key handling for constrained shapes (perfect square, circle, 45° lines)
- Add unit test for `recognizeShape` function

**Tech Stack:** React 18, Vite, vanilla JS (no TypeScript), Vitest for testing

**Spec:** This plan implements the D5 Shapes feature as described in the task.

## Global Constraints

- All visible text must go through `t("key")` from `src/lib/i18n.js` - add keys to en.json first
- After any text change run `node scripts/i18n-check.mjs` - must report no failures
- Use logical CSS (ms-, me-, ps-, pe-, start-, end-, text-start) instead of left/right
- Colours come from theme tokens (bg-background, text-foreground, bg-primary, etc.)
- No hard-coded colours in components except inside theme data
- Keep changes small and focused - touch only files the task needs
- Run `npx eslint src --quiet`, `npm run build`, `node scripts/i18n-check.mjs`, `npm ci --dry-run` before saying done

## Review Focus

1. **Shift key constraints not working** - When holding Shift while dragging a rectangle, it should constrain to square; ellipse to circle; line to 45° increments
2. **Shape recognition producing multiple objects** - A snapped arrow must be ONE object, not 3 separate marks
3. **Fill opacity not applied** - Fill opacity setting should affect the rendered shape
4. **Shape options not persisting** - Stroke/fill settings should persist across sessions
5. **Freehand snap with pen mode** - When shapeRecognition is ON and using pen, freehand drawing should snap to recognized shape

### Task 5: Implement Direct Shape Drawing in InkEngine

**Files:**
- Modify: `src/lib/canvas/ink/engine.js` (modify pointer handling for shape mode)

**Interfaces:**
- Consumes: `tool.shapeType`, `tool.shapeStrokeColor`, `tool.shapeStrokeWidth`, `tool.shapeFillColor`, `tool.shapeFillOpacity`
- Produces: Shape objects (type SHAPE) instead of strokes when in shape mode

- [ ] **Step 1: Modify pointerDown for shape mode**

When `tool.mode === "shape"` and a specific `shapeType` is set:
- Don't create a freehand stroke
- Instead, record the start point and create a live shape object
- Set `this.dragging = "shape"` and `this.liveShape = { startPoint, shapeType, ...options }`

- [ ] **Step 2: Modify pointerMove for shape mode**

When `this.dragging === "shape"` and `this.liveShape`:
- Calculate end point from current mouse position
- Apply Shift key constraints (see Task 6)
- Update `this.liveShape.endPoint` and mark dirty overlay

- [ ] **Step 3: Modify pointerUp for shape mode**

When `this.dragging === "shape"`:
- Create a proper SHAPE object from the live shape
- Use `createObject` from `@/lib/canvas/objects` with the shape type and options
- Call `this.cb.onUpdateObject` or add to objects array
- Push history
- Clear `this.liveShape` and `this.dragging`

- [ ] **Step 4: Render live shape in paintOverlay**

In `paintOverlay`, if `this.liveShape` exists, render it using `renderShape` (preview)
